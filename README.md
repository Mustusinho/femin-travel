# FeminTravel — Safety-First AI Trip Planner (Women + Friends)

FeminTravel is a mobile-first travel planning web app focused on **safer, smarter trips for women + friends**. It combines an interactive globe experience with AI-generated destination briefs, itinerary planning, lead capture, and affiliate-ready booking CTAs.

## What’s Inside

- **3D Interactive Globe** (`/globe`) — explore destinations visually
- **AI Destination Briefs** — safety-first tips, neighborhoods (high-level), packing, budgets
- **AI Chat Assistant** — contextual travel Q&A
- **Plan Flow (Wizard)** (`/plan`) — onboarding → results layout (itinerary + safety + booking)
- **Lead Capture** — email signup (optional WhatsApp/Telegram) for follow-ups
- **Blog** (`/blog`) — content pages for SEO + trust

> Safety note: FeminTravel avoids hyper-specific “this street is dangerous” claims. Safety guidance is practical + general and encourages checking official advisories when needed.

---

## Tech Stack

- **Next.js (App Router)** + React
- **Tailwind CSS** (premium feminine design tokens)
- **Supabase** (optional persistence: leads, plans, click tracking)
- **OpenAI API** (AI briefs/chat/plan generation)
- **Mapbox** (optional improved geocoding)
