# Earth detail texture

`earth-detail.jpg` is NASA Earth Observatory's Blue Marble: Next Generation
global image for June 2004, with topography and bathymetry, 5400 × 2700 pixels.
Source: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography/
Image credit: NASA Earth Observatory, Reto Stöckli and Robert Simmon.

Run `powershell -ExecutionPolicy Bypass -File scripts/download-earth-texture.ps1`
from the repository root to retrieve the original image. This is a historical
global composite for exploration, not current map or street-level imagery.
